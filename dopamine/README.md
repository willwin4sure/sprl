To start the bot, first create `dopamine/config.json` to contain:
```json
{
    "DISCORD_TOKEN": "<YOUR DISCORD TOKEN>",
    "GUILD_ID": "<YOUR GUILD ID>",
    "CHANNEL_ID": "<YOUR CHANNEL ID>"
}
```

You can find more information about how to get your Discord token [here](https://discord.com/developers/docs/topics/oauth2#bot-accounts).

Then run
```shell
~/.conda/envs/disc/bin/python ./dopamine/bot.py
```
